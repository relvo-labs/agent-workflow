# Skill catalog

Canonical portable catalog: `skills/*/SKILL.md`. Frontmatter is JSON (a YAML subset) so validation needs no YAML parser. Named relationships may be reciprocal; self-links and missing endpoints are errors. Ownership titles are unique.

- [task-intake](task-intake/SKILL.md): Authorization and acceptance boundaries.
- [dag-coordinate](dag-coordinate/SKILL.md): Dependency and resource scheduling.
- [writer-handoff](writer-handoff/SKILL.md): Exact writer ownership and transfer.
- [runtime-checkpoint](runtime-checkpoint/SKILL.md): Control acknowledgment and checkpoint state.
- [evidence-review](evidence-review/SKILL.md): Evidence correlation and bounded closure.

Install the **full checkout**, never isolated skill files. See [adoption](../adapters/adoption.md).
